# Horaire Automne 2026 — version iPad

Application web (installable sur l'écran d'accueil de l'iPad) synchronisée en temps réel avec l'application PC
`Horaire_Automne_2026.pyw` via Firebase Realtime Database.

Ce dépôt contient seulement le code de l'application : aucune donnée personnelle.
Les données sont stockées dans Firebase sous une clé secrète générée par le PC.

Adresse : https://ntouz300.github.io/horaire/
